Install the developer preview

Brevier is live on the Chrome Web Store. The developer preview is the same extension loaded manually in Developer mode — useful for testing builds. For everyday use, install the store version instead: it updates automatically and supports Pro checkout.

The preview is for testing. It does not update automatically and Chrome shows a developer-mode notice at startup. Pro purchases are handled by ExtensionPay for the Chrome Web Store build, so checkout is not available in the preview — install the store version to buy Pro.

Install in Developer mode

  1. Download the zip above and extract it to a folder (for example Downloads\brevier).
  2. Open chrome://extensions in Chrome.
  3. Turn on Developer mode in the top-right corner.
  4. Click Load unpacked and select the extracted folder — the one that contains manifest.json.
  5. Pin Brevier from the puzzle-piece menu, open a tab that is playing audio, and press Start in the popup.

The first time you use an engine, Brevier downloads its model (roughly 44 MB to 1.5 GB). Keep the connection up until the popup shows the model is ready; afterwards captions work offline.

Requirements and limits

  • Desktop Chrome 116 or newer (Chrome 138 or newer for built-in translation).
  • WebGPU is recommended for Parakeet and Whisper; Moonshine runs on CPU-only machines.
  • Preview installs do not auto-update — re-download the zip here for newer builds.
  • Chrome cannot capture chrome:// pages, the Chrome Web Store, or other extension pages.

Pro and supporting development

Buying Pro is how Brevier is funded: every purchase — $9.99 per year or $19.99 once — directly supports development of the on-device engines and keeps the project independent. ExtensionPay only completes purchases for the published store build, so checkout is not available in the preview.

The preview includes the full free tier: English captions on every engine, Chrome translation, every caption appearance setting, and 15 free Pro minutes every day.

Not ready to buy? Reporting bugs and sharing Brevier with someone who needs captions helps just as much — see Support.

Get the store version

The Chrome Web Store build installs in one click, updates automatically, and supports Pro checkout. If you buy Pro, sign in from the popup with the email used at checkout.
