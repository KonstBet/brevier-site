Support

Something not working, or a question the FAQ did not answer? Here is how to get help fast.

Install and update Brevier

Install Brevier from the Chrome Web Store — store builds update automatically and support Pro checkout. If you want to test builds, the developer preview is still available, but it does not auto-update and cannot complete Pro purchases. Buying Pro is what funds Brevier's development.

Report a bug or ask a question

The fastest way to reach the developer is GitHub Issues. Please include as much of the following as you can — it makes problems much faster to reproduce:

  • Your Chrome version (open chrome://version).
  • The selected engine (Auto, Parakeet, Moonshine, or Whisper) and language.
  • The site you were captioning, if the problem is specific to one.
  • What you expected to happen and what actually happened.

Open an issue on GitHub

Captions are not appearing

  1. Check that the tab can be captured. Chrome does not allow extensions to capture chrome:// pages, the Chrome Web Store, or other extension pages. Try a normal website that is playing audio.
  2. Give the first run a moment. The first time you use an engine, Brevier downloads the model (roughly 44 MB to 1.5 GB). Watch the progress in the popup and keep the network connected until it finishes.
  3. Try Auto or another engine. In the popup, set Engine to Auto, or pick a different engine. Auto falls back automatically if one cannot load, for example when WebGPU is unavailable.
  4. Reload the tab and start again. Stop captions, reload the page, and press Start.
  5. Check the spoken language. A mismatch between the spoken language setting and the audio produces empty or garbled captions.

Translation is not available

  • Chrome's built-in translator needs desktop Chrome 138 or newer.
  • Chrome may need to download a small language pack for the language pair on first use.
  • Hunyuan-MT translation is part of Pro and is not available in the EU, UK, or South Korea, where Brevier uses Chrome translation instead.

Pro license

  • After checkout, return to the popup and use “Already paid? Sign in” if Pro does not unlock immediately.
  • License checks need a network connection; offline, Brevier keeps the last known license state.
  • For purchase or receipt problems, open an issue and mention the email used at checkout.
  • Buying Pro directly supports Brevier's development.

Requirements recap

  • Desktop Chrome 116 or newer (138+ for Chrome translation).
  • A GPU with WebGPU is recommended for Parakeet and Whisper; Moonshine runs on CPU-only machines.
  • One model download per engine; afterwards, captions work offline.
