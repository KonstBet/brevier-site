Support

Something not working, or a question the FAQ did not answer? Here is how to get help fast.

Install and update Brevier

Install Brevier from the Chrome Web Store — store builds update automatically and support Studio Pro checkout. If you want to test builds, the developer preview is still available, but it does not auto-update and cannot complete paid purchases. Live captions are free; Studio Pro and optional tips fund development.

Report a bug or ask a question

The fastest way to reach the developer is GitHub Issues. Please include as much of the following as you can — it makes problems much faster to reproduce:

  • Your Chrome version (open chrome://version).
  • The selected engine (Auto, Parakeet, Parakeet TDT, or Qwen3-ASR) and language.
  • The site you were captioning, if the problem is specific to one.
  • What you expected to happen and what actually happened.

Open an issue on GitHub

Captions are not appearing

  1. Check that the tab can be captured. Chrome does not allow extensions to capture chrome:// pages, the Chrome Web Store, or other extension pages. Try a normal website that is playing audio.
  2. Give the first run a moment. The first time you use an engine, Brevier downloads the model (roughly 400 MB to 2.6 GB). Watch the progress in the popup and keep the network connected until it finishes.
  3. Try Auto or another engine. In the popup, set Engine to Auto, or pick a different engine. Auto falls back automatically if one cannot load, for example when WebGPU is unavailable.
  4. Reload the tab and start again. Stop captions, reload the page, and press Start.
  5. Check the spoken language. A mismatch between the spoken language setting and the audio produces empty or garbled captions.

Studio file transcription

  • Supported files: MP3, M4A, AAC, WAV, OGG, Opus and FLAC audio, plus MP4, M4V, MOV and WebM video (the audio track is transcribed).
  • Studio accepts files up to 1 GB. The free plan includes two file transcriptions of up to 30 minutes each and two on-device translation passes; Studio Pro adds unlimited file transcription up to 90 minutes and unlimited transcript translation.
  • The two free file transcriptions and two translation passes are tracked in this browser profile; clearing the extension's data resets both counts.
  • Studio starts with Qwen3-ASR 1.7B in Auto, or you can pick another speech model. The first load can take a few minutes. Long files on CPU can take a long time; keep the Studio tab open while it works.
  • If live captions are running, stop them before starting Studio. Only one speech engine can run at a time.
  • If Chrome cannot decode a file, try MP3, M4A, WAV or an MP4 with AAC audio. Studio does not use a cloud fallback.
  • Studio Pro keeps the 50 most recent transcripts on this device; older ones are removed automatically. Transcripts can be deleted from the recent list in Studio.

Translation isn't working

  • Chrome's built-in translator needs desktop Chrome 138 or newer.
  • Chrome may need to download a small language pack for the language pair on first use.
  • Hy-MT3 translation uses WebGPU. Without it, Brevier switches to Chrome translation automatically.

Studio Pro and thank-you passes

  • Live captions are free. Studio Pro is $4.99/month or $39/year and unlocks unlimited file transcription up to 90 minutes, transcript translation, Markdown/VTT export and local history.
  • Active yearly Patrons are grandfathered into Studio Pro. One-off tips ($10) and legacy Supporter passes keep their badge but do not unlock Studio Pro.
  • After checkout, return to Brevier; Studio checks access again when the page regains focus. Use “Already supported? Sign in” in the popup if the status does not appear.
  • Pass checks need a network connection; offline, Brevier uses the last cached status.
  • For purchase or receipt problems, open an issue saying only that you need purchase help. Do not post your email, receipt, or payment details; the developer will arrange private verification.

Purchases, renewal and refunds

  • Brevier is sold by the Brevier developer, not by Google. ExtensionPay and Stripe process the payment.
  • Studio Pro monthly and yearly plans renew automatically until cancelled. Cancel or update payment details from “Manage subscription” in the Brevier popup.
  • One-off tips and Supporter passes do not renew and do not unlock Studio Pro.
  • For a duplicate charge, accidental purchase or refund request, open a GitHub issue within 14 days without including personal or payment details, and the developer will arrange private verification. Refunds are reviewed case by case; cancelling stops future renewals but does not automatically refund a past period.
  • Prices are shown in USD at checkout and may include applicable taxes calculated by Stripe.

Requirements recap

  • Desktop Chrome 116 or newer (138+ for Chrome translation).
  • Brevier uses WebGPU when available and falls back to CPU transcription; WebGPU is recommended for live speed.
  • One model download per engine; afterwards, captions work offline.
